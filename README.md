# Categoría: Precios y cotizaciones

## Formato estándar para enviar cotizaciones al cliente

**Formato aprobado por Ignacio.** Toda cotización enviada a un cliente debe seguir esta estructura — tono cálido y profesional, sin lenguaje técnico interno ni explicaciones de por qué se cobra lo que se cobra:

```
📱 *Cotización — Cambio de pantalla [Modelo del equipo]*

*1. [Nombre de la opción]* — $[precio]
[Descripción breve, en tono cercano, de qué gana/pierde el cliente
con esta opción — huella, colores, garantía de fábrica, etc.]

*2. [Siguiente opción]* — $[precio]
[Descripción breve]

... (una línea por cada opción ofrecida)

_[Nota de cierre en cursiva: garantía, tiempos de entrega si aplica,
condiciones especiales]_
```

**Reglas al llenarlo:**

- Nunca usar en el texto al cliente: nombres de marca/proveedor (JK, GX, Hard OLED, Soft OLED), las siglas **SM/CM**, ni el desglose de mano de obra (solo el precio total). Tampoco explicarle al cliente el razonamiento interno de por qué un precio es fijo o por qué se calcula así — solo se presenta el resultado.
- **Para Android**, "Incell" sí se puede usar como nombre de categoría con el cliente (ej. "Pantalla Incell, sin marco"), y las palabras completas **"sin marco"/"con marco"** también se pueden usar y explicar si el cliente pregunta — lo único que nunca se dice son las siglas "SM"/"CM". **Para iPhone**, en cambio, "Incell" no se menciona — ahí se usan las 4 categorías ya definidas (LCD, LCD de mejor calidad, AMOLED, Original).
- Siempre incluir la nota de que las pantallas no tienen garantía una vez el equipo sale del local.
- Si la opción es una pantalla **OEM/original traída de China**, incluir el aviso de la sección "OEM" (ver más abajo).
- Si se ofrece la alternativa de pantalla importada de China (por precio muy alto en la opción nacional), aclarar tiempos de entrega (15 días, hasta 1 mes) y el anticipo del 50% antes de pedirla.
- **En toda cotización de iPhone (X en adelante), incluir siempre el aviso de "pieza desconocida"** si no se transfiere la memoria EEPROM, ofreciendo la transferencia como servicio adicional (ver tabla de costos por modelo más abajo). Nunca omitirlo.
- **Cada opción numerada siempre debe llevar su propia descripción corta** — nunca solo el nombre y el precio sin explicación. El cliente debe entender qué es lo que se le está cotizando en cada una.
- **Si el proveedor da precios de varias pantallas de la misma categoría** (ej. varias AMOLED, o varias LCD), **cotizar cada una como opción separada** — nunca elegir solo una y descartar las demás. Usar nombres progresivos genéricos (ej. "AMOLED", "AMOLED de mejor calidad", "AMOLED premium").
- **En iPhone, si hay pantallas "modo diagnóstico" disponibles** (Incell o AMOLED, ver sección de "Pantallas de memoria"), **ofrecerlas también como opciones normales** — sí se le puede decir "modo diagnóstico" al cliente. Si el precio que dan no especifica si es Incell o AMOLED, preguntar antes de cotizar.
- **Nunca inventar un precio, recargo o regla que no esté en este documento.** Si algo no está definido acá (por ejemplo, un modelo, categoría o rango de precio que no aparece), decirlo claramente y preguntar — no improvisar un número "parecido" a otro que sí esté documentado.
- **Si dan un precio de una calidad/marca de pantalla que no está en este documento** (distinta a JK, GX, Hard OLED, Soft OLED, Incell, Original, modo diagnóstico), **preguntar cómo se debe cotizar esa calidad** — esto también sirve como aviso de que el documento necesita actualizarse con ese caso nuevo.
- **Si el costo del repuesto que dan supera $1.200.000** (el techo superior de la tabla de mano de obra), **preguntar cómo cotizarlo en vez de extrapolar la fórmula más allá de ese rango** — no está definido qué pasa por encima de ese monto.

### Nota estándar de cierre (confianza + garantía)

Todos los ejemplos usan esta misma nota de cierre — genera confianza sin dejar de aclarar que no hay garantía sobre la pantalla una vez el equipo sale del local:

```
_Todo el proceso lo hacemos con el mayor cuidado, usando las mejores
herramientas e insumos y con la experiencia de nuestro equipo
técnico — ten la tranquilidad de que la instalación se hace de la
forma más profesional posible. Eso sí, como es habitual con este
tipo de repuestos, la pantalla no cuenta con garantía una vez el
equipo sale de nuestro local. Por eso te invitamos a probarlo con
calma, todo el tiempo que necesites, antes de retirarte._
```

## Política de cotización — Cambio de pantallas Android

### Objetivo

Definir cómo se calcula el precio al cliente para un cambio de pantalla Android, de forma que cualquier persona (o un agente de IA) pueda calcular el precio sin tener que preguntar cada vez.

### Fórmula base

```
Precio final al cliente = Valor del repuesto (costo de la pantalla) + Mano de obra
```

No se cobra un porcentaje sobre el repuesto — se cobra una **mano de obra escalonada**, que sube según el costo del repuesto. Esto hace el precio consistente y también cubre el mayor riesgo de instalar pantallas más costosas.

### Tabla de mano de obra según costo del repuesto

| Valor del repuesto | Mano de obra |
|---|---|
| $0 — $50.000 | $70.000 |
| $50.001 — $100.000 | $80.000 |
| $100.001 — $150.000 | $90.000 |
| $150.001 — $200.000 | $100.000 |
| $200.001 — $250.000 | $110.000 |
| $250.001 — $300.000 | $120.000 |
| **$300.001 — $500.000** | **$150.000 (tarifa plana)** |
| $500.001 — $1.200.000 | $200.000 (tarifa plana) |

**Nota sobre el tramo $300.001–$500.000:** en la primera versión que se documentó, este tramo seguía subiendo de $10.000 en $10.000 por cada $50.000 (igual que los tramos anteriores) hasta llegar a $200.000 en $500.000. Ignacio corrigió esto explícitamente: para todo el rango entre $300.001 y $500.000, la mano de obra es **siempre $150.000 fijo**, sin importar si el repuesto cuesta $310.000 o $490.000. No sigue la escalera de $10.000 por tramo en ese rango.

### ¿Por qué aumenta la mano de obra con el costo del repuesto?

No es solo por la instalación. También cubre:

- Riesgo de manipular repuestos de mayor valor.
- Garantía del trabajo.
- Insumos utilizados durante la reparación.
- Tiempo del técnico.
- Costos operativos y de domicilio para conseguir el repuesto.

### Ejemplos de cálculo

| Costo del repuesto | Mano de obra | Precio al cliente |
|---|---|---|
| $38.000 | $70.000 | $108.000 |
| $87.000 | $80.000 | $167.000 |
| $145.000 | $90.000 | $235.000 |
| $260.000 | $120.000 | $380.000 |
| $480.000 | **$150.000** | **$630.000** |
| $780.000 | $200.000 | $980.000 |

**Nota:** el ejemplo de $480.000 originalmente se había calculado con la tabla vieja (mano de obra $160.000 → precio $640.000), antes de la corrección del tramo $300.001–$500.000 a tarifa plana de $150.000. Ya se recalculó con la regla corregida ($480.000 + $150.000 = **$630.000**) — **confirmado por Ignacio.**

### Términos SM y CM

- **SM = Sin Marco.** **CM = Con Marco.** El "marco" es el borde plástico del display, el que trae originalmente el celular y al que va asentada la pantalla nueva.
- Cuando el cambio es **con marco (CM)**, la pantalla queda mejor asentada e instalada.
- **Lo único que nunca se le dice al cliente son las siglas "SM"/"CM" en sí.** Sí está bien decirle "pantalla sin marco" / "pantalla con marco" con las palabras completas, y explicarle qué es el marco si pregunta — igual que "Incell" también se puede usar como nombre de categoría con el cliente en Android (a diferencia de iPhone, donde no se menciona).

### Aspectos técnicos que siempre hay que aclarar al cliente (Android)

- **Huella en pantalla (sensor de huella bajo el display):** si el celular original tenía sensor de huella integrado en la pantalla y se instala una pantalla de calidad **Incell**, el sensor de huella bajo pantalla **deja de funcionar**. Esto debe quedar claro en la cotización.
- **Pantallas sin garantía:** la cotización debe dejar explícito que las pantallas no tienen garantía (ver [garantías y políticas](garantias-y-politicas.md)).
- **Calidad Incell sin marco (SM), cuando el original era AMOLED:** suelen quedar feas, se les puede filtrar la luz por los lados, y se parten con más facilidad porque el display no queda asentado sobre el marco.
- **Calidad con marco (CM):** quedan bien instaladas/asentadas, pero los colores no van a ser idénticos a los del original (porque no es AMOLED).
- **Calidad AMOLED (no original):** los colores pueden variar un poco respecto al original, aunque sea AMOLED.
- **Tasa de refresco:** en algunos modelos con pantalla de alta tasa de refresco (90Hz/120Hz), la tasa de refresco del repuesto puede variar respecto al original — vale la pena aclararlo también.
- **Pantallas originales en Android:** solo se consiguen pantallas originales para **algunos modelos de Samsung** — no está disponible como opción para toda la gama Android.

### Pantallas importadas desde China

**¿Cuándo ofrecerla?** Sobre todo en modelos donde la pantalla local/nacional sale muy costosa — el caso típico son los **Samsung serie S**, que suelen tener pantallas nacionales extremadamente caras. En esos casos, se le puede ofrecer al cliente la alternativa de pedir una pantalla importada desde China, que puede resultar mucho más económica, **si el cliente está de acuerdo con las condiciones**.

**Condiciones que hay que explicarle al cliente:**

- **Tiempo de entrega:** aproximadamente **15 días** en llegar a Colombia, pero puede demorar **hasta un mes**.
- **Anticipo:** el cliente debe abonar **la mitad (50%)** antes de que se haga el pedido a China (es decir, antes de pedirla, no solo al autorizar la reparación).
- Vienen en diferentes calidades y precios, que se cotizan igual que las demás (LCD / LCD de mejor calidad / AMOLED / Original, según lo que consiga el proveedor chino).

**Regla de mano de obra para pantallas de China — distinta a la tabla nacional:**

A diferencia de la tabla de mano de obra nacional (que arranca en $70.000), para las pantallas traídas desde China la mano de obra arranca más alto, porque implica el trabajo adicional de gestionar la compra al exterior:

- A la pantalla china **más barata** disponible: mano de obra **$100.000**.
- Por cada **$50.000 adicionales** de costo del repuesto por encima de esa más barata: sube **$10.000** más de mano de obra (mismo patrón de escalón de $10.000 por cada $50.000 que se usaba en la tabla nacional original, solo que aquí el punto de partida es $100.000 en vez de $70.000).

*(Nota: esta regla de escalón para China no menciona un tope ni una tarifa plana como el tramo $300.001–$500.000 de la tabla nacional — de momento se documenta tal cual se explicó, sin asumir que aplique la misma tarifa plana acá.)*

### "OEM" — aviso obligatorio en pantallas de China

El proveedor de China vende algunas pantallas como **"OEM"**, término con el que ellos dicen que es una pantalla **original**. **Este aviso debe dársele siempre al cliente cuando se cotice una pantalla OEM/original traída de China:**

> El proveedor de China nos la vende como pantalla original (OEM), pero no podemos garantizar al 100% que sea una pieza original de fábrica, ya que no se compra directamente a un proveedor autorizado. Aun así, la experiencia instalando este tipo de pantallas ha sido muy buena.

Este aviso es especialmente importante en estas pantallas porque suelen ser **costosas y no tienen garantía** — el cliente debe saber a qué está accediendo antes de aceptar la cotización.

## Política de cotización — Pantallas iPhone

### 1. iPhone 6 hasta iPhone 8 Plus

**Modelos incluidos:** iPhone 6, 6 Plus, 6s, 6s Plus, 7, 7 Plus, 8, 8 Plus.

**Calidad ofrecida:** LCD (réplica). Todos estos modelos originalmente ya venían con pantalla LCD (retroiluminación) — nunca usaron AMOLED, así que no hay decisión de calidad que tomar aquí.

**Precio:** fijo, **$130.000**, para cualquiera de esos modelos. No hace falta consultar el costo del repuesto — es un precio único.

### 2. iPhone X en adelante (hasta iPhone 15 Pro Max)

A partir del iPhone X el mercado de repuestos se complica: existen varias calidades/marcas de pantalla. La forma de cotizar de Ignacio es **vender una categoría de calidad, no una marca específica de repuesto** — el cliente nunca necesita saber si la pantalla es JK, GX, Hard OLED, Soft OLED o Incell; solo necesita entender que tiene una opción económica, una intermedia, una AMOLED y una original.

**Regla de oro: nunca revelar al cliente los nombres comerciales/técnicos internos** (JK, GX, Hard OLED, Soft OLED, Incell, ni el proveedor). Al cliente solo se le habla en términos de estas 4 categorías:

- **LCD**
- **LCD de mejor calidad**
- **AMOLED**
- **Original**

Razón de por qué no se revela la marca/proveedor al cliente: si se le dice el nombre técnico, el cliente puede ir a cotizar a otro lado con ese mismo nombre y encontrar un precio distinto (más barato o más caro), y pensar que le están cobrando mal — o generar desconfianza. Al hablar solo de "categoría de calidad", el precio queda consistente sin importar qué proveedor específico se usó ese día.

#### Categoría 1 — LCD

Incluye cualquier pantalla LCD (retroiluminada) disponible en el mercado, sin importar el fabricante.

*Ejemplos internos (no se dicen al cliente):* LCD económica genérica, JK (LCD con mejores colores, pero sigue siendo tecnología LCD/retroiluminada), otras LCD equivalentes.

Al cliente siempre se le dice simplemente: **"Pantalla LCD"**.

**Precio:** si el costo del repuesto está en el rango habitual (aprox. entre $50.000 y $200.000):

```
Precio = costo del repuesto + $100.000
```

Esta regla de +$100.000 aplica a la pantalla LCD **más económica** que se consiga, siempre que cueste menos de $200.000 (normalmente están entre $50.000 y $150.000).

**Si la pantalla LCD/Incell más barata que se consigue ya vale $200.000 o más** (esto incluye a las pantallas Incell, como las del iPhone XR/11): en ese caso se cobra **+$150.000** de mano de obra en vez de +$100.000.

#### Categoría 2 — LCD de mejor calidad

Cuando hay más de una opción LCD disponible con precios distintos, se puede ofrecer una "de mejor calidad" (internamente puede ser la JK u otra LCD de gama más alta).

Al cliente tampoco se le dice la marca — solo: **"Pantalla LCD de mejor calidad"**.

**Precio:** misma fórmula, **+$100.000** sobre el costo de esa pantalla.

La elección de cuál proveedor/repuesto usar para esta categoría depende de cuál genere mejor margen de utilidad ese día.

#### Categoría 3 — AMOLED

Incluye todas las variantes OLED del mercado.

*Ejemplos internos (no se dicen al cliente):* Hard OLED, Soft OLED, GX (cuando sí es AMOLED real), OLED genérica.

Al cliente solo se le dice: **"Pantalla AMOLED"**.

**Precio — regla general:**

- Si la pantalla AMOLED cuesta **hasta $150.000** → `Precio = costo del repuesto + $150.000`
- Si la pantalla AMOLED cuesta **más de $150.000** → `Precio = costo del repuesto + $200.000`

**Excepción comercial (opción de entrada):** si incluso la pantalla AMOLED más económica que se consigue ya cuesta más de $250.000, se puede ofrecer una primera opción cobrando solo **+$150.000** en vez de saltar directo a +$200.000 — para que el precio no se dispare y el cliente no descarte la reparación por parecer muy cara. Si el cliente pide una calidad superior o una segunda opción AMOLED, esas sí se cotizan con la regla general de **+$200.000**.

**⚠️ Regla importante — no colapsar varias calidades AMOLED en una sola:** cuando el proveedor da precios de más de una pantalla AMOLED (ej. GX, Hard OLED, Soft OLED — todas AMOLED reales), **hay que cotizar cada una como una opción separada al cliente, no elegir solo una.** Cada opción se calcula con la misma fórmula de esta categoría, aplicada a su propio costo. Se presentan con nombres progresivos genéricos, de más económica a más cara, sin decir la marca de ninguna:

- **Pantalla AMOLED** (la más económica de las disponibles)
- **Pantalla AMOLED de mejor calidad** (si hay una segunda opción)
- **Pantalla AMOLED premium** (si hay una tercera opción)

Se usan tantos niveles como precios distintos haya ese día (puede ser solo 1, 2, o hasta 3) — nunca se resume todo en una sola pantalla AMOLED cuando hay varias disponibles. Esta misma lógica de "no colapsar, mostrar cada nivel" aplica igual a la Categoría 1/2 de LCD cuando hay más de dos opciones LCD con precios distintos.

**Cada opción SIEMPRE debe llevar su propia descripción corta** para que el cliente entienda qué está pagando (nunca solo el nombre y el precio, sin explicación). Para los niveles AMOLED, la descripción se mantiene simple y progresiva — no hay que inventar diferencias técnicas complicadas entre ellas, basta con decir que cada nivel da colores un poco mejor que el anterior. Ejemplo de redacción:

- *Pantalla AMOLED:* "Colores muy similares a los del original, con una leve variación posible. No es una pieza original."
- *Pantalla AMOLED de mejor calidad:* "Da colores un poco mejor que la opción anterior."
- *Pantalla AMOLED premium:* "Da colores aún mejor que las dos opciones anteriores."

#### Categoría 4 — Original

Pantallas originales, **sin cambio de memoria EEPROM**.

**Precio habitual:**

```
Precio = costo del repuesto + $200.000
```

**Excepción:** para modelos de muy alto costo (ejemplo dado: iPhone 15 Pro Max), se puede subir a **+$250.000** — esto no es una regla fija, queda a criterio del asesor ("puede que"), no una tarifa obligatoria.

#### Memoria EEPROM del display (iPhone)

Las pantallas de iPhone tienen un pequeño chip de memoria (EEPROM) que guarda los seriales originales de la pantalla. Esto es lo que hace que el sistema (iOS) reconozca la pantalla como "original".

- **Si no se transfiere esa memoria** al instalar una pantalla nueva —aunque sea una pantalla **original**—, el celular queda funcionando con normalidad, pero el sistema muestra un aviso de **"pieza desconocida"** (no reconoce la pantalla como original).
- **Para evitar ese aviso**, hay que transferir físicamente el chip EEPROM de la pantalla original vieja del cliente a la pantalla nueva.
- **Si el cliente ya se había cambiado la pantalla antes** (en otro lugar) y esa pantalla anterior no conservó/no tenía el chip EEPROM original, ya no hay chip que transferir — el aviso de "pieza desconocida" va a aparecer sin importar lo que se haga. Esto es importante avisarle al cliente de antemano, para que no piense que es un error de instalación.
- **También se puede hacer en algunas pantallas réplica** (no solo en originales) — pero no en todas. Hay que validar con el proveedor si esa pantalla específica acepta el cambio de EEPROM antes de ofrecérselo al cliente.

**Costo de la transferencia de EEPROM — según el modelo:**

| Modelo | Costo de la transferencia de EEPROM |
|---|---|
| iPhone X hasta iPhone 12 (toda la serie 12) | $80.000 adicionales |
| iPhone 13 hasta iPhone 15 (toda la serie 13, 14 y 15) | $150.000 adicionales |

**⚠️ Aviso obligatorio en toda cotización de iPhone (X en adelante):** siempre hay que incluirle al cliente una nota explicando que, si no se hace la transferencia de la memoria del display, el celular puede mostrar el aviso de "pieza desconocida" — y ofrecer la transferencia como servicio adicional con su costo (según la tabla de arriba). No es opcional omitir este aviso — debe ir en toda cotización de pantalla iPhone, sin importar la calidad elegida.

#### Pantallas de memoria ("de diagnóstico")

Son pantallas réplica que traen un **chip que imita los seriales originales** — evitan que salga el aviso de "pieza desconocida" **sin necesitar** la transferencia manual del chip EEPROM de la pantalla vieja (ver arriba). Según cómo quede registrada por el sistema, pueden aparecer como "pantalla usada" (aunque sea nueva) o incluso como "pantalla original" — pero nunca como "pieza desconocida". Existen en distintas calidades de panel — pueden ser de calidad **Incell** (colores más sencillos/feos, pero igual evitan el aviso) o de calidad AMOLED/superior.

**Disponibilidad:** las pantallas de diagnóstico calidad Incell **solo existen desde el iPhone 12 en adelante** — para X, XS, XS Max, 11, 11 Pro y 11 Pro Max no existe esta opción. El proveedor da un **precio aparte** para la versión de diagnóstico, siempre más cara que la Incell normal (no es el mismo costo de repuesto) — y **no siempre hay disponibilidad**, hay que consultar con el proveedor si la tiene ese día.

**Precio — confirmado por Ignacio:**

- **Pantalla de diagnóstico, calidad Incell, para iPhone 12, 13, 14 y 15:** `costo del repuesto (el que dé el proveedor para la versión de diagnóstico) + $150.000`. Aunque los colores sean más sencillos (por ser Incell), el cliente no verá el aviso de "pieza desconocida" — ese es el valor que está pagando de más frente a una LCD normal.
- **Pantalla de diagnóstico de mayor calidad (equivalente a AMOLED o superior):** se cotiza igual que la categoría Original — `costo del repuesto + $200.000`.
- **⚠️ Pendiente de confirmar:** para iPhone 16 y 17, ¿existe también esta versión de diagnóstico Incell por separado de la Incell normal (+$200.000, ver sección 3), y si es así, cuánto se le sube? No asumir el mismo +$150.000 de la serie 12-15 sin confirmarlo.

**Ambas variantes se ofrecen al cliente como opciones normales de la cotización** — no son un extra oculto ni algo que solo se mencione si el cliente pregunta. Cada variante se presenta con "modo diagnóstico" en el nombre (esto sí se le dice) — lo que nunca se revela es que es una réplica con chip imitador, ni la marca/proveedor:

- Variante calidad Incell → **"Pantalla LCD (modo diagnóstico)"**
- Variante calidad AMOLED/superior → **"Pantalla AMOLED (modo diagnóstico)"**

**En la descripción de cada una, siempre aclarar dos cosas:**
1. Que esta tecnología evita el aviso de "pieza desconocida" **sin necesidad de reemplazar el circuito de memoria (EEPROM)**.
2. Que, aun así, el sistema puede detectarla en algunas ocasiones como **"pieza original"** o como **"pieza usada"** — aunque la pantalla sea completamente nueva. No es un resultado garantizado de una sola forma.

**⚠️ Regla importante — preguntar si no se especifica cuál es:** si Ignacio (o quien dé el precio) menciona una "pantalla de modo diagnóstico" sin aclarar si es calidad Incell o AMOLED, **hay que preguntar cuál de las dos es** antes de armar la cotización — nunca asumir una por defecto, ya que cambian tanto el recargo ($150.000 vs $200.000) como el nombre que se le muestra al cliente.

### Cómo interpretar los precios que dan los proveedores

Los proveedores a veces contestan con números "recortados", sin decir "mil" — por ejemplo, dicen "45, 35, 50, 30" para referirse a $45.000, $35.000, $50.000, $30.000. **Ninguna pantalla vale menos de $10.000 pesos** (mucho menos $200 o $30 pesos tal cual), así que cualquier número bajo que dé un proveedor como costo de una pantalla se debe interpretar como miles de pesos, no como el valor literal. Ejemplos: "200" → $200.000; "250" → $250.000; "30" → $30.000.
